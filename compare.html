How rules are matched
Identical
The rule text is the same (ignoring spaces), or both sides are the same “Undefined” / “Too many source nodes” marker.
Equivalent
Same logic, written differently: reordered terms, De Morgan forms like !(A || B), or redundant terms. Proven by normalising both rules, or by checking every input combination (up to 12 regulators).
Different
The two rules give different outputs for some input. The row shows the regulators that were added, removed or flipped, the share of inputs on which they agree, and example inputs where they diverge.
Unverified
More than 12 regulators and no difference turned up in 2,048 sampled inputs, but it can't be proven. It is not counted as a match.
Rule lost
The original has a real rule; the refactored file has Undefined or Too many source nodes.
Rule gained
The reverse: the original had no rule, the refactored file does.
Marker changed
Both sides have no rule, but a different marker (Undefined vs Too many source nodes).
Only in original Only in refactored
The target appears in just one file.
Coverage map
Every gene in both files is put in one group: both files have a real rule, the refactored file has one where the original had Undefined or Too many source nodes (rescued), only the original has one, or neither does. A rule that is just 0 or 1 is a constant and does not count as a real rule.
Regulator overlap
For genes where both files have a real rule: the Jaccard overlap of the two regulator sets (shared ÷ all). It ignores gates and signs, so it is shown next to a count of rules with the same regulators but different logic.
Missing nodes
A node is any gene named in a file, as a target or as a regulator. From rules alone: a mismatch is fully explained when the two rules agree once the absent genes are held at a constant state (0 or 1); for a lost or gained rule, when every regulator is absent. With both Cytoscape.csv files: when every change in the gene's available regulators involves a gene absent from the other network. Either way, a target in one file only counts here when it is not a node in the other file.
Partly missing nodes
From rules alone: absent genes are involved, but the rules still differ after accounting for them (or there are over 12 regulators). With edges: some of the changed regulators are absent genes and some are not.
Edges changed
Only with edges: the gene's available regulators changed, although all of those regulators exist in both networks.
Not node-related / Same inputs, rule changed
From rules alone: every regulator named in the rule exists in both networks. With edges: the gene had exactly the same available regulators in both runs, so the difference comes from the code or from other data such as expression.
Can't tell from rules
One side is Too many source nodes, which lists no regulators. Add both Cytoscape.csv files to resolve it.
